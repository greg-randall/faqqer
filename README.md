# FAQ Generation Thorugh Content Atomization 

This project takes a WordPress XML export from a WordPress site. It turns that file into a clean database of "Atomic Facts" and then builds a full FAQ.

## Pipeline Overview

The project has ten steps. It goes from raw HTML to a categorized, approved FAQ.

### 1. The Scripts

* `01_extract_content.py`: Reads the WordPress XML file. It removes HTML tags and saves clean Markdown files. It uses the URL to name the files.
* `02_process_content.py`: Uses **GPT-4o-mini** to read each file. It pulls out "Atomic Facts" (simple, true statements) and saves them as JSON.
* `03_generate_embeddings.py`: Adds vector embeddings (math lists) to every fact using **OpenAI**.
* `04_cluster_facts_hdbscan.py`: Uses HDBSCAN and Recursive K-Means to group thousands of facts into topics. It exports a CSV file.
* `05_generate_faq.py`: Reads the fact clusters. It uses an LLM to write a Question and Answer pair for each cluster.
* `06_categories.py`: Reads the FAQ. It looks at all the questions to invent natural categories. Then it sorts every question into one of those categories.
* `07_add_urls_to_sources.py`: Scans the original Markdown files to find live URLs and adds them to the FAQ sources.
* `08_faq_llm_review.py`: Uses an LLM to **audit** (check facts) and **evaluate** (score utility) the generated answers.
* `09_faq_reviewer.php`: A simple web interface for humans to review, edit, and approve the generated FAQ entries.
* `10_generate_wp_html.py`: Converts the approved FAQ entries into WordPress-ready HTML blocks (details/summary).

### 2. Helper Modules

* `openai_helper.py`: Handles requests for OpenAI Chat (GPT-4o).
* `openai_helper_embedding.py`: Handles batching for OpenAI Embeddings (`text-embedding-3-large`).

## Data Formats

### Phase 1: Clean Markdown (`/content/`)

**Generated by:** `01_extract_content.py`

Each file is one page from the website. We add data to the top of the file to know where it came from.

```markdown
# Academic Calendar
**Source URL:** [https://example.edu/academics/academic-calendar/](https://example.edu/academics/academic-calendar/)
**ID:** 1245

## Fall 2025 Semester
* Orientation begins August 11...

```

### Phase 2: Atomic Facts JSON (`/content_processed/`)

**Generated by:** `02_process_content.py`

The LLM pulls facts out of the page. It adds missing context. For example, "The deadline" becomes "The Fall 2025 registration deadline."

```json
{
  "page_topic": "Academic Calendar",
  "facts": [
    "The Fall 2025 Orientation for New Employees is from Monday, August 11 through Friday, August 15.",
    "The Fall 2025 registration bills are available on the portal on August 15."
  ],
  "source_file": "academics_academic_calendar.json"
}

```

### Phase 3: Embedded Facts JSON (`/content_embedded/`)

**Generated by:** `03_generate_embeddings.py`

This is the same data as Phase 2. But now it has a vector array for machine learning.

```json
{
  "page_topic": "Academic Calendar",
  "facts": [ ... ],
  "source_file": "academics_academic_calendar.json",
  "facts_with_embeddings": [
    {
      "text": "The Fall 2025 Orientation...",
      "vector": [0.0123, -0.0456, 0.0098, ... ]
    }
  ]
}

```

### Phase 4: Cluster Report (`data/fact_clusters.csv`)

**Generated by:** `04_cluster_facts_hdbscan.py`

A spreadsheet list of facts grouped by topic.

| cluster_label | source | fact |
| --- | --- | --- |
| 5_1 | hr_calendar.json | The Fall 2025 Orientation... |
| 5_1 | employees_events.json | Orientation is mandatory for new hires... |
| 12_0 | admissions_fees.json | The application fee is $50... |

### Phase 5: FAQ JSON (`data/faq_raw.json`)

**Generated by:** `05_generate_faq.py`

The system takes a cluster of facts and writes a Q&A pair.

```json
[
  {
    "id": "5_1",
    "questions": "When is orientation for new students?",
    "answer": "Orientation for the First Year Class runs from Monday, August 11 through Friday, August 15.",
    "source_facts": [ ... ],
    "verified": false
  }
]

```

### Phase 6: Categorized FAQ (`data/faq_categorized.json`)

**Generated by:** `06_categories.py`

The final file. It has the same data as Phase 5, but now each item has a category tag like "Admissions" or "Student Life."

```json
[
  {
    "id": "5_1",
    "questions": "When is orientation for new students?",
    "answer": "Orientation for the First Year Class...",
    "category": "Academic Schedule"
  }
]

```

### Phase 7: Enriched JSON (`data/faq_categorized.json`)

**Generated by:** `07_add_urls_to_sources.py`

This overwrites the file from Phase 6. It finds the original Markdown files and attempts to extract the live URL for every fact source.

```json
"source_facts": [
  {
    "fact": "The Fall 2025 Orientation...",
    "source": "academics_calendar.json",
    "live_url": "https://example.edu/academics/academic-calendar/"
  }
]
```

### Phase 8: Audited FAQ (`data/faq_categorized.json`)

**Generated by:** `08_faq_llm_review.py`

The system adds an audit status and utility scores to each entry.

```json
{
  "id": "5_1",
  "questions": "...",
  "answer": "...",
  "audit_status": "PASS",
  "audit_reason": "Factually supported.",
  "utility_score": 8.7,
  "score_reason": "High demand topic affecting all employees."
}
```

### Phase 9: Reviewed FAQ (`data/faq_categorized.json`)

**Generated by:** `09_faq_reviewer.php` (Manual Edit)

The human review tool saves back to the same JSON file. It adds status flags and edits the text.

```json
{
  "id": "5_1",
  "questions": "When is orientation for new employees?",
  "answer": "Orientation runs from August 11-15.",
  "category": "HR",
  "status": "approved",
  "admin_notes": "Rewrote for clarity."
}
```

### Phase 10: WordPress HTML (`data/faq_final.html`)

**Generated by:** `10_generate_wp_html.py`

The final output ready for copy-pasting. It only includes items marked as `approved`.

```html
<!-- wp:heading {"level":2} -->
<h2 class="wp-block-heading">HR</h2>
<!-- /wp:heading -->

<!-- wp:details -->
<details class="wp-block-details"><summary>When is orientation for new employees?</summary>
<!-- wp:paragraph {"placeholder":"Type / to add a hidden block"} -->
<p>Orientation runs from August 11-15.</p>
<!-- /wp:paragraph -->
</details>
<!-- /wp:details -->
```

## Usage

**Prerequisites:**

* Python 3.10+
* OpenAI API Key (`OPENAI_API_KEY` env var)
* Dependencies: `openai`, `pandas`, `scikit-learn`, `markdownify`

**Execution:**

```bash
# 1. Extract content from WP Export
python 01_extract_content.py wordpress-export.xml

# 2. Extract facts (Cost: GPT-4o-mini tokens)
python 02_process_content.py

# 3. Generate Embeddings (Cost: OpenAI Embedding tokens)
python 03_generate_embeddings.py

# 4. Analyze & Cluster (Free - Local Compute)
python 04_cluster_facts_hdbscan.py

# 5. Generate FAQ (Cost: GPT-4o-mini tokens)
python 05_generate_faq.py

# 6. Categorize FAQ (Cost: GPT-4o-mini tokens)
python 06_categories.py

# 7. Add URLs (Local)
python 07_add_urls_to_sources.py

# 8. LLM Audit (Cost: GPT-4o-mini tokens)
python 08_faq_llm_review.py

# 9. Review (Human)
# Run a local PHP server: php -S localhost:8000
# Open browser to: http://localhost:8000/09_faq_reviewer.php

# 10. Generate HTML (Local)
python 10_generate_wp_html.py

```
